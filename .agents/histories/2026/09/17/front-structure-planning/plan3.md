# 개요

- 좌우폭이 너무 큼. 1024px 랩탑 말고 768px tablet정도가 맘에 듬
- 하단 툴바도 같이 사이즈 맞춰야하지 않나?
- 서비스 명칭 정리해줄게
  - blog: 인스타그램 같은거 (니가 커뮤니티라고 명명한)
  - memo: 개인 메모장
  - feed: 스트리머 활동 알림, 가격 알림 이런거 feed 라는 서비스에서 다 해야겠다
- 검색바에서 N이랑 AI는 왜있는거야 내 캡쳐 보고 따라한거 같은데 필요없어 그런거까진
- 지금 작업하는 페이지가 회원 로그인한 사용자 기준인거 같은데 비회원은 어떻게 표현할거임?
- 서비스 카드에서 편집 지우고, 더보기도 지워. 고정적으로 제공할거고 갯수가 많아지면 carousel 처럼 좌우 화살표해서 넘기도록 할거임

---

# 구현 계획

> community 관련된건 다 blog로 변경해줘 냅두지말고

## 답변

`community`로 남아 있는 경로, 디렉토리, 컴포넌트, 타입, 화면 문구를 모두 `blog` 기준으로 변경한다.

## 작업 범위

- `/community` 라우트를 제거하고 `/blog` 라우트를 만든다.
- `features/community` 디렉토리를 `features/blog`로 변경한다.
- `CommunityContainer`, `CommunityView`, `CommunityPostCard`, `communityTypes` 이름을 각각 `BlogContainer`, `BlogView`, `BlogPostCard`, `blogTypes`로 변경한다.
- 화면 표시 문구의 `커뮤니티`를 `blog` 기준으로 변경한다.
- 플랫폼 홈의 서비스 런처 링크도 `/blog`로 변경한다.

## plan3 화면 조정

- 플랫폼 홈 폭을 `1040px`에서 `768px` 기준으로 줄인다.
- 상단바와 하단 툴바도 플랫폼 홈에서는 `768px` 기준으로 맞춘다.
- 검색바의 `N`, `AI` 요소를 제거한다.
- 서비스 런처는 `blog`, `memo`, `feed` 고정 서비스 중심으로 정리한다.
- 서비스 런처의 `편집`, `더보기`를 제거한다.
- 비회원 기준의 홈으로 보이도록 로그인 CTA를 제공하고, 로그인 사용자 전용처럼 보이는 영역은 줄인다.

# 추가사항

- 서비스 카드에서 '서비스', 'choimory.dev에서 사용할 도구들' 같은거 지우고 카드만 
- 서비스명 영문 말고 한글로 표시
- 서비스 많아졌을때 카드 어떻게 동작하는지 궁금하니까 더미 서비스 10개 만들어봐
- 서비스 카드 밑에 카드들은 그냥 지워버리고 하나씩 대화하면서 추가하자

## 구현 계획

- 서비스 런처 카드 상단의 `서비스`, `choimory.dev에서 사용할 도구들` 문구를 제거한다.
- 서비스명은 화면 표시 기준으로 한글을 사용한다.
- 내부 id와 라우트는 `blog`, `memo`, `feed`처럼 영문으로 유지한다.
- 서비스가 많아졌을 때의 동작을 보기 위해 총 10개 서비스를 표시한다.
- 10개 서비스는 가로 스크롤 런처로 구성하고, 이후 carousel 좌우 화살표를 붙이기 쉬운 구조로 둔다.
- 서비스 카드 밑의 로그인 CTA, 고정 서비스 안내 카드는 제거한다.
- 결과적으로 `/` 화면은 상단바, `choimory.dev`, 검색바, 서비스 아이콘 런처, 하단 툴바만 남긴다.

# 추가사항

- 서비스 카드가 하단 스크롤바 말고 좌우 화살표가 있었으면
- 검색바가 너무 허전한데 돋보기 같은거나 검색버튼같은거라도 뭐 있음 좋겠네
- 서비스 카드 밑의 내용들은 비로그인 사용자면 서비스 소개하는 랜딩페이지 같은걸 보여줄까?
- 로그인 사용자면 본인의 서비스 관련 피드들을 받고

## 구현 계획

- 서비스 런처는 하단 스크롤바를 노출하지 않고 좌우 화살표 버튼으로 넘기도록 변경한다.
- `ServiceLauncherCard`를 클라이언트 컴포넌트로 바꾸고, 버튼 클릭 시 내부 리스트를 `scrollBy`로 이동시킨다.
- 검색바는 실제 `<form>` 구조로 분리하고, 왼쪽에 돋보기 아이콘, 오른쪽에 `검색` 버튼을 둔다.
- 검색 기능은 아직 연결하지 않고 submit 기본 동작만 막는다.
- 서비스 카드 아래에는 비회원 사용자 기준의 서비스 소개 랜딩 섹션을 추가한다.
- 로그인 사용자용 개인 피드 영역은 추후 인증 상태가 생기면 같은 위치에서 교체할 수 있게 구조를 분리한다.
