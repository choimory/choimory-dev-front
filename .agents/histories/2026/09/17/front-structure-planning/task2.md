# 개요

- `plan1.md`에서 논의한 플랫폼 홈과 커뮤니티 서비스를 실제 코드로 1차 구현한다.
- PC에서도 모바일 앱처럼 중앙 콘텐츠 폭을 좁게 유지하는 방향을 우선 적용한다.
- 상세한 색상, 간격, 게시글 카드 완성도는 이후 화면을 보면서 조정한다.

# 플랫폼형 화면 1차 구현

## 작업 내용

- `/` 루트에 플랫폼 홈 화면을 구현함.
- `/community`에 커뮤니티/SNS 서비스 화면을 구현함.
- `shared/ui`에 공통 프레임, 상단 앱 바, 하단 네비게이션, 아이콘, 좁은 중앙 콘텐츠 레이아웃을 추가함.
- `features/platform`에 플랫폼 홈 데이터, 컴포넌트, 컨테이너를 추가함.
- `features/community`에 커뮤니티 피드 데이터, 게시글 카드, 화면 컴포넌트, 컨테이너를 추가함.
- `globals.css`에 화면 색상 토큰과 라이트/다크 OS 테마 대응을 추가함.
- `README.md`를 현재 구현된 라우트와 구조 기준으로 갱신함.

## 구현된 화면

- `/`
  - 플랫폼 홈
  - 오늘 요약
  - 자주 쓰는 서비스
  - 최근 활동
  - 플랫폼형 하단 네비게이션
- `/community`
  - 커뮤니티 서비스 피드
  - 피드 필터
  - 글 작성 진입 영역
  - 게시글 카드
  - 커뮤니티 내부 하단 네비게이션

## 다음 조정 대상

- 실제 브라우저에서 PC와 모바일 폭을 보며 간격, 색상, 카드 비율을 조정해야 함.
- 플랫폼 홈의 서비스 카드와 커뮤니티 게시글 카드의 실제 데이터 구조를 확정해야 함.
- 로그인/회원가입을 새 구조 안에서 어느 시점에 다시 붙일지 결정해야 함.

# plan2 기반 플랫폼 홈 조정

## 작업 내용

- `plan2.md` 분석 내용을 바탕으로 `/` 플랫폼 홈을 포털형 메인에 가깝게 조정함.
- 플랫폼명을 코드상 `choimory.dev`로 변경함.
- `/` 플랫폼 홈의 PC 콘텐츠 폭을 `max-w-[1040px]`로 넓힘.
- 기존 서비스별 큰 카드 구조를 제거하고, 하나의 `ServiceLauncherCard` 안에 하위 서비스 아이콘들이 모이는 구조로 변경함.
- 서비스 런처에 메모, 방송, 가격, 쇼핑, 뉴스, 커뮤니티, 지도, 더보기 항목을 표시함.
- 기본 테마를 다크로 변경함.
- 추후 라이트/다크/시스템 설정 확장을 위해 `[data-theme="light"]` 토큰 구조는 남김.
- 더 이상 사용하지 않는 `PlatformServiceCard.tsx`를 삭제함.

## 유지한 방향

- `/community`는 서비스 내부 화면이므로 기존처럼 모바일형 좁은 피드 레이아웃을 유지함.
- `NarrowContent`는 커뮤니티 같은 서비스 내부 화면용으로 유지함.
- `WideContent`는 플랫폼 메인처럼 더 넓게 쓰는 화면용으로 추가함.

## 검증 상태

- `npx tsc --noEmit`, `npm run lint`, `npm run build`는 아직 실행하지 않음.
