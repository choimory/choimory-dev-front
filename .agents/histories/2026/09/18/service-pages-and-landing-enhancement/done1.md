# 개요

- 서비스 화면구조와 랜딩페이지 고도화 작업을 마무리했다.
- 플랫폼 홈, 블로그, 피드, 상단바, 하단 툴바, 로그인 사용자용 플랫폼 홈 카드 구조를 정리했다.
- 실제 API 연동 없이 mock/view data 기반의 화면 구조를 구현했다.

# 완료 내용

## 플랫폼 홈

- 플랫폼 홈을 여러 하위 서비스를 담는 서비스 허브 구조로 정리했다.
- 비로그인 사용자에게 블로그와 피드를 소개하는 랜딩 섹션을 구성했다.
- 로그인 사용자용 플랫폼 홈에 `내 피드` 카드를 유지했다.
- `내 피드` 카드와 같은 레벨로 서비스별 대형 피드 카드를 추가했다.
- 블로그 서비스 카드에는 다음 지표를 표시했다.
  - 내가 쓴 글
  - 내가 쓴 댓글
  - 팔로워 수
  - 팔로잉 수
- 블로그 서비스 카드 하단에는 알림 카드 4개를 표시했다.
- 피드 서비스 카드에는 다음 지표를 표시했다.
  - 관찰 중인 아이템
  - 관찰 중인 스트리머
- 피드 서비스 카드 하단에는 알림 카드 4개를 표시했다.
- 메모, 일정, 가계부는 준비 중 대형 카드로 표시했다.
- 서비스별 대형 카드 자체 hover는 제거하고 내부 지표/알림 카드에 hover를 적용했다.

## 상단바

- 상단바에 검색, 알림, 로그인/로그아웃 액션을 구성했다.
- 검색 오버레이는 `document.body` portal 렌더링 구조로 변경했다.
- 검색바가 브라우저 viewport 기준으로 표시되도록 했다.
- 검색바 위치를 화면 중앙보다 살짝 위로 조정했다.
- 검색 오버레이 위에 브랜드 로고를 표시했다.
- 검색 오버레이의 브랜드 로고는 타자기 애니메이션이 동작하도록 했다.
- 알림 탭을 `전체 / 블로그 / 피드` 서비스 탭 구조로 변경했다.
- 로그인 상태 상단바 액션을 `내 정보`에서 `로그아웃`으로 변경했다.

## 하단 툴바

- 플랫폼 하단 툴바를 `홈 / 공지사항 / 서비스 / 내 정보` 구조로 정리했다.
- 블로그 하단 툴바를 `홈 / 인기 / 팔로잉 / 내 블로그` 구조로 정리했다.
- 피드 하단 툴바를 `홈 / 인기 / 추적 / 내 피드` 구조로 정리했다.
- 피드의 `추적` 탭 아이콘은 막대그래프 계열 `barChart` 아이콘을 사용하도록 했다.

## 공통 UI

- 공통 `Icon`에 필요한 아이콘을 추가하고 더 이상 사용하지 않는 아이콘을 정리했다.
- 서비스 화면 공통 상단바와 하단 네비게이션 구조를 여러 서비스에서 재사용하도록 정리했다.
- 브랜드 로고는 화면별 필요에 따라 애니메이션 여부를 다르게 적용했다.
