# step2 후보

## 플랫폼 홈 랜딩 고도화

현재 플랫폼 홈 비로그인 랜딩은 blog/feed 중심 안내까지 반영되었지만, 아직 카드형 설명에 가깝다.

개선 후보:

- `blog`, `feed`를 핵심 서비스로 더 잘 보여주는 랜딩 섹션 구성
- 준비 중 서비스는 별도 coming soon 느낌으로 정리
- 활성 서비스와 미래 서비스의 차이를 더 명확하게 표시

## feed 화면 디테일 개선

현재 feed 화면은 구조 뼈대 수준이다.

개선 후보:

- 비회원 화면을 더 서비스 소개답게 정리
- 회원 화면에 관심 피드, 최근 알림, 추적 중 항목 레이아웃을 더 구체화
- feed 서비스가 스트리머 활동 알림과 가격 알림을 합친 서비스라는 점을 더 명확하게 표현
- feed 하단 툴바 항목 확정

## 서비스별 하단 툴바 정책 정리

현재 하단 툴바 후보:

blog:

- 피드
- 인기
- 작성
- 홈

feed:

- 피드
- 관심
- blog
- 홈

남은 고민:

- 서비스별로 다른 하단 툴바를 유지할지
- 플랫폼 홈으로 돌아가는 항목은 항상 둘지
- 같은 위치에 같은 역할을 배치할지
- 검색과 작성 같은 액션을 하단에 둘지, 상단 액션 또는 별도 화면으로 분리할지

상단바에는 `choimory.dev / blog`, `choimory.dev / feed`처럼 서비스 맥락이 표시된다.

개선 후보:

- `/ blog`, `/ feed` 같은 서비스명에 색상 또는 스타일 추가
- 서비스별 홈 로고 느낌을 조금 더 명확하게 만들기
- 다만 320px 모바일에서도 줄바꿈과 표시 안정성을 유지해야 한다.

# 추천 step2

추천 step2는 다음 조합이다.

1. feed 화면 디테일 개선
2. 서비스별 하단 툴바 정책 정리

이유:

- `/feed`는 이제 라우트와 구조는 생겼지만 아직 안내/뼈대 느낌이 강하다.
- feed를 먼저 다듬으면 플랫폼, 블로그, 피드 3축이 더 선명해진다.
- 하단 툴바 정책을 함께 정리하면 blog와 feed가 각각 따로 노는 느낌을 줄일 수 있다.

다음 구현 방향:

- feed 비회원 화면을 서비스 소개형으로 고도화
- feed 회원 화면의 관심 피드/최근 알림/추적 중 항목을 더 구체화
- blog/feed 하단 툴바 항목과 역할을 비교해 정리
- 필요한 경우 상단 서비스명(`/ blog`, `/ feed`)의 스타일 보강은 이후 단계로 분리

# step2 구현 전 분석

## 현재 상태

- 플랫폼 홈은 `blog/feed` 활성, `memo/schedule/account-book` 준비 중으로 정리되었다.
- `/feed` 라우트와 `features/feed` 구조는 생겼다.
- feed는 guest/member 분기 가능하다.
- 하지만 feed 화면은 아직 소개와 목록 뼈대 수준이다.
- blog와 feed 하단 툴바는 각각 따로 정해져 있어서 정책이 덜 정리되어 있다.

## 문제점

1. feed 비회원 화면이 아직 서비스의 매력을 충분히 설명하지 못한다.
   - 스트리머 활동 알림과 가격 알림이 한 서비스 안에 들어간다는 컨셉은 있지만, 화면에서 강하게 보이지 않는다.
   - 왜 로그인해야 하는지가 조금 약하다.
2. feed 회원 화면이 아직 실제 사용 화면처럼 보이지 않는다.
   - 요약 카드와 최근 알림은 있지만, 내가 뭘 추적 중인지가 약하다.
   - 관심 피드, 추적 중 항목, 최근 이벤트가 구분되면 더 서비스답게 보인다.
3. 하단 툴바 정책이 서비스별로 일관되지 않다.
   - blog: `피드 / 인기 / 작성 / 홈`
   - feed: `피드 / 관심 / blog / 홈`
   - `blog` 항목이 feed 하단에 들어가는 건 살짝 어색하다.
   - 플랫폼형 앱이면 각 서비스 하단에서 `홈`은 플랫폼 홈으로, 나머지는 서비스 내부 기능으로 두는 편이 좋다.

- 두 번째: 서비스 핵심 분류/탭
- 세 번째: 주요 액션 또는 알림/작성
- 네 번째: 플랫폼 홈

## feed 화면 개선 방향

비회원:

- 상단 소개 카드 강화
  - 방송 시작과 가격 하락을 한 피드에서 확인한다는 메시지
  - 로그인/회원가입 CTA
- 알림 유형 카드
  - 스트리머 활동
  - 가격 하락
  - 사용자 정의 조건
- 로그인하면 가능한 것 섹션
  - 관심 대상 저장
  - 목표 가격 설정
  - 알림 히스토리 확인

회원:

- 요약 카드 유지
  - 추적 중
  - 새 알림
  - 관심 항목
- 추적 중인 항목 섹션 추가
  - 스트리머 샘플
  - 상품 샘플
- 최근 이벤트 섹션 정리
  - 방송 시작
  - 가격 하락
  - 새 콘텐츠
- 나중에 실제 API를 붙이기 쉽게 ViewModel에 데이터를 분리한다.
