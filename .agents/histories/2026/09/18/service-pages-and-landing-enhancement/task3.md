# 개요

- `plan2.md`의 추가사항 분석을 바탕으로 즉시 반영 가능한 하단 툴바 정책과 문구 수정을 구현했다.
- 화면 체감이 큰 상단 검색/알림 UI도 공통 상단바 액션으로 추가했다.
- 실제 검색 API, 알림 API, 검색 결과 화면, 알림 읽음 처리는 아직 구현하지 않았다.

# 추가사항 구현

## 작업 내용

- 플랫폼 비로그인 랜딩의 `blog`, `feed` 영어 문구를 `블로그`, `피드`로 변경함.
- 플랫폼 하단 툴바를 `홈 / 공지사항 / 서비스 / 내 정보`로 변경함.
- 블로그 하단 툴바를 `홈 / 인기 / 팔로잉 / 내 블로그`로 변경함.
- 피드 하단 툴바를 `홈 / 인기 / 추적 / 내 피드`로 변경함.
- 상단 검색 버튼 클릭 시 중앙 검색 오버레이가 표시되도록 함.
- 상단 알림 버튼 클릭 시 알림 팝오버가 표시되도록 함.
- 공통 아이콘에 `megaphone`, `trophy`, `telescope`를 추가함.

## 비로그인 랜딩 문구 한글화

수정함:

- `src/features/platform/components/GuestLandingSection.tsx`

변경 내용:

- `공개 blog 피드`를 `공개 블로그 피드`로 변경
- `feed에서 방송과 가격 알림 흐름 확인`을 `피드에서 방송과 가격 알림 흐름 확인`으로 변경
- `blog와 feed부터 둘러보고`를 `블로그와 피드부터 둘러보고`로 변경

## 하단 툴바 정책 변경

수정함:

- `src/features/platform/components/PlatformHomeView.tsx`
- `src/features/blog/components/BlogView.tsx`
- `src/features/feed/components/FeedView.tsx`

플랫폼:

- 홈
- 공지사항
- 서비스
- 내 정보

블로그:

- 홈
- 인기
- 팔로잉
- 내 블로그

피드:

- 홈
- 인기
- 추적
- 내 피드

각 서비스에서 하단 툴바의 `홈`은 현재 영역의 홈으로 둔다.

플랫폼 홈으로 돌아가는 이동은 상단 로고 `choimory.dev`가 담당한다.

## 상단 검색과 알림 UI 추가

추가함:

- `src/shared/ui/TopBarActions.tsx`

수정함:

- `src/shared/ui/AppTopBar.tsx`

`AppTopBar`의 검색/알림/로그인 액션 영역을 `TopBarActions` 클라이언트 컴포넌트로 분리했다.

검색 UI:

- 검색 버튼 클릭 시 화면 배경이 흐려지고 중앙 검색 오버레이가 표시됨
- 검색 대상 selectbox 제공
  - 전체
  - 블로그
  - 피드
- 검색어 입력창 제공
- 검색 버튼 제공

알림 UI:

- 알림 버튼 클릭 시 상단바 근처에 알림 팝오버 표시
- 탭 제공
  - 전체
  - 서비스별
- 알림 샘플 목록 제공
  - 새 댓글
  - 방송 시작
  - 가격 하락

아직 실제 검색과 알림 기능은 연결하지 않았다.
