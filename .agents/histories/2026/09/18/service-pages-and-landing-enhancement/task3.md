# 개요

- `plan2.md`의 추가사항 분석을 바탕으로 즉시 반영 가능한 하단 툴바 정책과 문구 수정을 구현했다.
- 화면 체감이 큰 상단 검색/알림 UI도 공통 상단바 액션으로 추가했다.
- 실제 검색 API, 알림 API, 검색 결과 화면, 알림 읽음 처리는 아직 구현하지 않았다.

# 추가사항 구현

## 작업 내용

- 플랫폼 비로그인 랜딩의 `blog`, `feed` 영어 문구를 `블로그`, `피드`로 변경함.
- 플랫폼 하단 툴바를 `홈 / 공지사항 / 서비스 / 내 정보`로 변경함.
- 블로그 하단 툴바를 `홈 / 인기 / 팔로잉 / 내 블로그`로 변경함.
- 피드 하단 툴바를 `홈 / 인기 / 추적 / 내 피드`로 변경함.
- 상단 검색 버튼 클릭 시 중앙 검색 오버레이가 표시되도록 함.
- 상단 알림 버튼 클릭 시 알림 팝오버가 표시되도록 함.
- 공통 아이콘에 `megaphone`, `trophy`, `telescope`를 추가함.

# 검색 오버레이와 알림 탭 추가 구현

> 구현내용 task3에 추가

## 답변

`plan3.md`의 추가사항2 분석을 바탕으로 상단 검색 오버레이와 알림 탭 구조를 추가 구현했다.

## 작업 내용

수정함:

- `src/shared/ui/TopBarActions.tsx`

검색 오버레이:

- 검색 오버레이를 `document.body` portal 렌더링 구조로 유지함.
- 검색 패널 위치를 브라우저 viewport 기준 정중앙보다 살짝 위인 `top-[42%]`로 조정함.
- 검색바 위 중앙에 기존 `BrandLogo`를 추가함.
- 검색바의 검색 대상 selectbox, 검색어 input, 검색 button 구조는 유지함.

알림 팝오버:

- 알림 탭을 `전체 / 서비스별`에서 `전체 / 블로그 / 피드`로 변경함.
- 알림 샘플 데이터에 `service` 필드를 추가함.
- 선택한 알림 탭에 따라 알림 목록이 필터링되도록 변경함.
- `전체` 탭에서는 모든 알림을 표시하고, `블로그`와 `피드` 탭에서는 해당 서비스 알림만 표시함.

## 검증 상태

아직 테스트는 실행하지 않았다.

# 검색화면 로고 애니메이션 적용

> 구현내용 task3에 추가

## 답변

`plan3.md`의 검색화면 로고 애니메이션 적용 범위에 따라 검색 오버레이의 로고만 애니메이션이 동작하도록 수정했다.

## 작업 내용

수정함:

- `src/shared/ui/TopBarActions.tsx`

변경 내용:

- 검색 오버레이에 표시되는 `BrandLogo`에서 `isAnimated={false}`를 제거함.
- 검색화면 로고는 `<BrandLogo size="md" />` 형태로 변경되어 기본값인 `isAnimated=true`가 적용됨.
- 상단바 로고는 `<BrandLogo isAnimated={false} size="sm" />` 상태를 유지함.
- 플랫폼 홈 로고는 기존 `<BrandLogo size="lg" />` 상태를 유지함.

## 검증 상태

아직 테스트는 실행하지 않았다.
