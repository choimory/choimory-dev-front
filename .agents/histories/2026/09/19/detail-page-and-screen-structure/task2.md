# 개요

- `plan2.md`의 1차 구현 범위인 플랫폼 공지 모달, 마이페이지 설정 모달, 블로그 게시글 상세 개선을 진행했다.
- 실제 API 연동 없이 기존 mock/view data 기반으로 화면 상호작용과 상세 UX를 먼저 구성했다.
- 상태가 필요한 화면은 클라이언트 컴포넌트로 전환했다.

# 구현사항

## 공지사항 상세 모달

공지사항 목록 카드 클릭 시 상세 모달이 열리도록 구현했다.

구현 내용:

- `PlatformNoticeView`를 클라이언트 컴포넌트로 전환했다.
- 선택된 공지사항 상태를 `useState`로 관리한다.
- 공지사항 카드 클릭 시 선택된 공지의 상세 모달을 표시한다.
- 모달 바깥 영역 또는 `닫기` 버튼 클릭 시 모달을 닫는다.
- 공지사항 mock 데이터에 상세 본문 `content`를 추가했다.

## 마이페이지 설정 모달

마이페이지 설정 카드 버튼 클릭 시 설정별 모달이 열리도록 구현했다.

구현 내용:

- `MeView`를 클라이언트 컴포넌트로 전환했다.
- 선택된 설정 항목 상태를 `useState`로 관리한다.
- `MeSettingCard`에 `onSelect` 이벤트 props를 추가했다.
- 설정 카드 버튼 클릭 시 설정별 모달을 표시한다.
- 마이페이지 하단 네비게이션의 `내 공간` 라벨을 `내 정보`로 변경했다.

설정별 모달 내용:

- 개인정보 수정
  - 이메일은 변경 불가 입력 필드로 표시
  - 닉네임 입력 필드 표시
  - 닉네임 중복체크 버튼 표시
  - 자기소개 입력 영역 표시
- 사이트 설정
  - `light`, `dark`, `system` 테마 선택 radio 표시
- 2차 인증
  - 이메일 인증 radio 표시
  - 모바일 앱 인증은 미구현 상태로 표시
- 회원 탈퇴
  - 위험 액션 영역으로 강조
  - 실제 탈퇴 API 전까지 화면 구조만 표시

## 블로그 게시글 상세 개선

블로그 게시글 상세 화면의 정보 밀도와 액션 구조를 개선했다.

구현 내용:

- 기존 큰 좋아요/댓글 지표 카드 2개를 제거했다.
- 게시글 목록과 비슷한 작은 액션 줄을 추가했다.
- 좋아요, 댓글, 공유, 북마크 버튼을 추가했다.
- 좋아요 수와 댓글 수를 작은 텍스트로 표시했다.
- 댓글 입력 영역을 추가했다.
- 댓글 카드를 더 compact하게 조정했다.
- 댓글 좋아요 버튼을 추가했다.
- 댓글 좋아요 수를 표시했다.
- 대댓글 예시를 추가했다.
- 대댓글 안에 멘션 예시를 추가했다.

## 추가사항 보정

`plan2.md`의 추가사항 재분석 내용을 기준으로 화면 디테일을 보정했다.

플랫폼 보정:

- 플랫폼 홈 비회원 랜딩 라벨을 `choimory.dev 시작하기`에서 `BrandLogo(애니메이션 없음) / welcome` 구조로 변경했다.
- 서비스 화면 상단 라벨을 `BrandLogo(애니메이션 없음) / services` 구조로 변경했다.
- 공지사항 화면 상단 라벨을 `BrandLogo(애니메이션 없음) / notice` 구조로 변경했다.
- 공지사항 상세 모달 폭을 `max-w-[520px]`에서 `max-w-[640px]`로 키웠다.
- 공지사항 상세 모달 라벨을 `notice/detail`에서 `notice / post`로 변경했다.
- 서비스 카드 우측 문구를 활성 서비스는 `이동`, 준비 중 서비스는 `준비 중`으로 통일했다.

내 정보 보정:

- 내 정보 설정 카드는 우측 버튼만 클릭하는 방식에서 카드 전체 클릭 방식으로 변경했다.
- 중첩 버튼 구조를 피하기 위해 우측 액션은 버튼이 아니라 배지 형태의 `span`으로 표시했다.
- 일반 설정 카드 액션명은 `열기`로 통일했다.
- 탈퇴 설정 카드 액션명은 `탈퇴`로 유지했다.
- 개인정보 수정 모달 하단에 `수정하기` 버튼을 추가했다.
- 사이트 설정 모달은 `테마 설정` 카드 안에 `light`, `dark`, `system` radio를 표시하는 구조로 변경했다.
- 사이트 설정 모달 하단에 `저장` 버튼을 추가했다.
- 2차 인증 모달에서 모바일 앱 인증은 disabled radio와 `미구현` 표시를 함께 보여주도록 변경했다.
- 2차 인증 모달 하단에 `저장` 버튼을 추가했다.
- 모달 depth 라벨을 `me/settings`에서 `me / settings`로 변경했다.

블로그 상세보기 보정:

- `BlogPostDetailView`를 클라이언트 컴포넌트로 전환했다.
- 게시글 상세 본문 영역의 순서를 `본문 → 액션줄 → 좋아요/댓글수`에서 `액션줄 → 좋아요/댓글수 → 본문`으로 변경했다.
- 댓글 입력 영역을 게시글 카드 내부에서 `blog / comments` 섹션으로 이동했다.
- 댓글 입력창 옆에 `작성` 버튼을 추가했다.
- 댓글 섹션 라벨을 `comments`에서 `blog / comments`로 변경했다.
- `답글 달기` 버튼 클릭 시 해당 댓글 아래에 대댓글 입력창이 표시되도록 `replyingCommentId` 상태를 추가했다.
- 대댓글 입력창에도 `작성` 버튼을 추가했다.

## 피드백 반영 보정

추가사항 구현 후 피드백을 기준으로 공지사항 상세보기, 2차 인증, BrandLogo depth 표기를 추가 보정했다.

공지사항 상세보기 보정:

- 공지사항 상세 모달 폭을 `max-w-[640px]`에서 `max-w-[720px]`로 더 키웠다.
- 공지사항 상세 모달 내부 여백을 키웠다.
- 공지사항 상세 본문을 별도 패널처럼 보이도록 `bg-surface-strong` 영역 안에 배치했다.
- 공지사항 상세 라벨을 `notice / post`에서 `BrandLogo(애니메이션 없음) / notice`로 변경했다.

2차 인증 모달 보정:

- 2차 인증 모달에 `2차 인증 사용 여부` 카드를 추가했다.
- 사용 여부 선택지는 `사용`, `미사용` radio로 구성했다.
- 인증 방식 선택 영역을 별도 카드로 분리했다.
- 인증 방식 선택지는 `이메일 인증`, `모바일 앱 인증`으로 구성했다.
- 모바일 앱 인증은 disabled radio와 `미구현` 배지를 함께 표시했다.

BrandLogo depth 표기 보정:

- blog 비회원 시작 영역의 `choimory.dev / blog 시작하기`를 `BrandLogo(애니메이션 없음) / blog`로 변경했다.
- feed 홈의 `choimory.dev / feed`를 `BrandLogo(애니메이션 없음) / feed`로 변경했다.
- 플랫폼 홈, 서비스, 공지사항의 BrandLogo depth 표기는 유지했다.

- blog 게시글 상세 화면이 댓글 작성과 대댓글 입력 예시를 포함한다는 설명 추가
