# 개요

서비스 도메인 페이지별 페이지 소개 헤더를 정리하는 작업(plan1~2, task1~2)을 완료했다. 처음엔 단순히 소개 카드 디자인 통일로 시작했으나, 진행 중 카드 자체를 없애는 방향으로 바뀌었고, 이어서 사이트 전체 헤더 패턴과 문구 톤까지 정리하는 범위로 확장됐다.

---

# 1차: 페이지 소개 카드 공용화

- `shared/ui/PageIntroCard.tsx`, `shared/ui/StatCard.tsx` 신설.
- 플랫폼(공지사항/서비스), 블로그(인기/팔로잉), 피드(인기/관찰) 6개 화면에 `PageIntroCard` 적용.
- 내블로그(`BlogMeSettingsView`)에 프로필+카운팅 카드 신규 추가(`BlogRelationModal`, `BlogProfileCard`로 공용화), 내피드는 소개카드 제거하고 프로필카드 추가, `SummaryCard` 중복을 `StatCard`로 통합.
- README에 용어집(서비스/도메인) 섹션 신설.

# 2차: 헤더 규격화(px-1 통합)

- 화면 곳곳에 흩어져 있던 `px-1` 헤더 패턴을 전수 조사(18곳, 5개 패턴 A~E)한 뒤, 사용자 피드백(스크린샷 3장)을 반영해 `PageIntroCard`에서 카드 배경/테두리를 완전히 제거(로고+eyebrow+타이틀+설명만 배경 위에 배치, 320px에서 로고 줄바꿈되도록 `flex-wrap` 적용).
- 신규 `shared/ui/SectionHeader.tsx`(로고 없이 eyebrow+heading, 선택적 우측 action 링크) 추가.
- eyebrow 2티어 규칙 확정: 화면 최상단(로고 포함, `PageIntroCard`) vs 섹션 구분용(로고 없음, `SectionHeader`).
- `blog / me`, `feed / me`, `blog / @{nickname}`, 게시글 상세 최상단을 `PageIntroCard`로 승격.
- 13곳(블로그/피드/플랫폼 전반)을 `SectionHeader`로 통일하면서 eyebrow가 자유 한글이거나 서비스명이 빠졌던 곳을 `{서비스} / {도메인}` 포맷으로 정리.
- heading 톤을 명사형으로 축약("사용할 서비스를 선택하세요" → "서비스" 등).

# 3차: 사이트 전체 문구 톤 통일

- `~합니다/~입니다/~습니다` 등 격식체 종결어미를 코드 주석을 제외하고 전수 조사(총 113곳, 17개 파일)해 스크립트로 일괄 치환.
  - 안내/설명 문구 → 해요체 권유형(`~해요/~해보세요`)
  - 시스템 알림·이벤트 로그 → 완료형(`~했어요/~됐어요`)
  - 게시글 mock 댓글(대화체)은 제외
- 블로그 게시글에 `title` 필드 신설, 목록 카드와 상세 페이지 헤더에 실제 제목 노출.
- 서비스 목록에 "커뮤니티"(준비 중) 추가.
- 블로그/피드 인기 heading을 "실시간 순위"로, 블로그 팔로잉 heading을 "팔로잉"으로 통일.

# 4차: 기타 소소한 변경

- 피드 관찰 heading "관찰 목록" → "관찰".
- `Icon.tsx`에 3인 그룹 아이콘(`users`) 신규 추가, 커뮤니티 서비스 아이콘을 `chat`에서 `users`로 교체.

# README 반영

- 용어집(서비스/도메인) 섹션 신설.
- 아키텍처 기준에 `PageIntroCard`/`SectionHeader` 2티어 규칙, eyebrow/heading/description 작성 기준 명시.
- 코드 규칙에 "문구" 소단원 신설(해요체, 권유형/완료형 구분, 댓글 예외).
- 현재 화면 상태의 화면 요소 목록을 새 컴포넌트/구조에 맞게 갱신.

# 최종 검증

- 매 단계마다 `npx tsc --noEmit`, `npm run lint` 통과 확인.
- `npm run dev`로 변경된 라우트 전체(플랫폼/블로그/피드/인증/마이페이지) HTTP 200과 서버 로그 무에러 확인.
- 브라우저 확장(claude-in-chrome) 미설치로 실제 화면 시각 확인은 진행하지 못함.
