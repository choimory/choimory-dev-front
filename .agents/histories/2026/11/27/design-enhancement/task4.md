## 실행 중 처리한 것

- **D1 권한 요청 2건 허용**:
  - hallmark 브라우저 검사(`sloplint --render`)로 피드 화면 5개 확인. 지시서의 검증 방법 그대로.
  - D1이 만든 측정 스크립트(`/tmp/choimory-stage3-d1-feed-check.cjs`) 실행. 허용 전에 내용을 확인함. 로컬 dev 서버 화면을 Chrome으로 열어 등록 행 줄 수, 입력칸 높이·테두리 대비·포커스 링을 재기만 하고 파일은 쓰지 않음.
- **지시서 오류 발견**: 지시서에는 인기 순위 애니메이션이 "140ms 간격"으로 적혀 있었지만, 실제 코드와 테스트는 0·70·140ms(세 번째 행이 140ms, 간격은 70ms). D1·C 모두 테스트 기준인 70ms 간격을 유지함.
- **브라우저 검사 제약**: A·B·C·D2는 Codex 샌드박스가 Chrome 실행과 로컬 서버 연결을 막아 브라우저 검사를 못 함. 취합 단계에서 Claude가 대신 실행.

# .hallmark 폴더 필요 여부

> .hallmark는 꼭 있어야하는거야?

## 답변

앱을 돌리는 데는 전혀 필요 없음. hallmark 스킬이 작업 중에 쓰는 작업 폴더(약 23MB)이고, `src`, `design.md`, `package.json` 어디에서도 참조하지 않음. 다만 이번 리디자인이 끝날 때까지는 지우면 안 됨.

## 폴더 구성

| 항목 | 내용 | 지금 필요한가 |
|---|---|---|
| `before.json` | 0단계 기록(링크 61, 입력 필드 20, 핸들러 88) | **필요**. 4단계 유지 항목 대조용. 화면이 이미 바뀌어서 다시 만들 수 없음 |
| `before/` | 작업 전 스크린샷 125장 | **필요**. 4단계 before/after 비교 파일의 before 쪽 |
| `before.txt` | 작업 전 점검 결과 | 참고용. before/after 수치 비교 |
| `stage3/` | GPT 작업자 5명의 보고서 | **필요**. 3단계 취합과 최종 보고 |
| `shots/` | 가장 최근 검사 스크린샷 | 검사할 때마다 덮어쓰는 임시 파일 |
| `preflight.json`, `salt` | hallmark 사전 점검 캐시, 내부 값 | 없어도 다음 실행 때 다시 만들어짐 |

## git 상태

- `.hallmark/.gitignore`가 `shots/`, `before/`, `before.json`, `before.txt`, `compare.html`은 이미 제외.
- `preflight.json`, `salt`, `stage3/`는 지금 그대로 커밋하면 같이 올라감. 커밋할 때 `.hallmark/` 폴더는 빼고 커밋하면 됨.

## 추천

1. 4단계가 끝날 때까지는 그대로 둠.
2. 4단계가 끝나면 둘 중 선택.
   - **가. 폴더째 지우고 git에서도 제외 (추천)**: 필요한 내용(before/after 수치, 지운 것, 수정한 테스트, 작업자 보고 요약)은 task·done 문서에 옮겨 적은 뒤 지움. 루트 `.gitignore`에 `.hallmark/`를 넣어 나중에 hallmark를 다시 써도 git에 안 섞이게 함.
