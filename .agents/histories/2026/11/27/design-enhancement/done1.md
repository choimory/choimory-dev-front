# 디자인 고도화 작업 마무리

> 작업 마무리하자 커밋은 내가할거니까 done, readme만 작성하고 .hallmark 관련 파일들은 지워줘

## 답변

- done1.md에 전체 요약 작성, calendar.md를 DONE으로 변경, README.md에 디자인 시스템 반영.
- `.hallmark/` 폴더 삭제(필요한 내용은 task 문서와 이 문서에 옮겨 둠).
- 커밋은 하지 않음.

## 작업 요약

- 기존 화면은 모든 요소가 같은 둥근 카드 박스이고, 카드 안 카드, 제목 위 경로형 라벨, 알약 모양, 보라→파랑 그라디언트, 가운데 점 메타 문구 등 AI가 만든 티가 나는 패턴이 많았음.
- hallmark 스킬의 redesign(full) 방식으로 디자인 시스템(Cobalt 테마)을 새로 정하고, 공용 UI와 25개 화면의 구성을 다시 짬.
- 내용(문구·숫자)과 동작(링크·폼·핸들러)은 모두 유지했고, 로고는 겉모습을 그대로 고정함.

## 진행 방식

| 단계 | 담당 | 내용 |
|---|---|---|
| 0. 사전 기록 | Claude | 25개 화면 before 스크린샷, 유지 항목 기록, 점검, 테스트 기준선 |
| 1. 디자인 시스템 | Claude | Cobalt 테마, 토큰, 폰트, 로고 전용 토큰, `design.md` 고정 |
| 2. 공용 UI와 셸 | Claude | `shared/ui` 17개 컴포넌트 |
| 3. 도메인별 화면 | GPT Sol 6.2 작업자 5명 (병렬, paseo) | platform, auth·me, blog, feed 목록, feed 상세 |
| 4. 통합 검증 | Claude + 리뷰어 2명 + GPT Sol 6.2 작업자 1명 | 유지 항목 대조, 빌드, 라이트 테마, 브라우저 확인, 마무리 리뷰(Claude·GPT), 리뷰 수정 |

- 단계가 끝날 때마다 멈춰서 결과를 확인받고 다음 단계로 넘어감.
- 테스트는 수정하지 않고 승인 목록으로 올린 뒤, 승인된 것만 고침.

## 단계별 결과

### 0단계 사전 기록

- 테스트 기준선: 97개 파일, 574개 통과.
- 25개 화면을 1280·1440·1920·375 폭에서 125장 촬영.
- 유지 항목 기록: 링크 61, 입력 필드 20, 핸들러 88.
- 점검: FAIL 36, REFLEX 34, WARN 8.

### 1단계 디자인 시스템

- hallmark가 뽑은 후보 3개(Wayfind, Ultraviolet, Cobalt) 중 Cobalt 선택. 코드 형태 로고와 결이 같고, 파란 강조색이 로고와 맞고, 구분선 중심이라 카드 남발 문제를 정면으로 고칠 수 있음.
- 한글 대응 폰트 구성(IBM Plex Sans KR, Familjen Grotesk, JetBrains Mono, 로고용 Geist Mono).
- 기존 토큰 이름은 유지하고 값만 Cobalt 역할로 연결해 테스트가 깨지지 않게 함.
- 다크 기본, 라이트 유지. 다크는 hallmark 다크 모드 규칙으로 다시 계산.
- 로고 전용 토큰으로 로고 색·폰트를 리디자인 전 값에 고정.
- Tailwind 글자 크기 이름은 유지(로고 크기와 기존 화면 보호), 한글 조판 보정(`word-break: keep-all`, 제목 폭 제한 해제).

### 2단계 공용 UI와 셸

- 키캡 버튼, 오목한 트레이 탭, 모서리 깎은 패널·태그, 구분선 목록 행, 단색 셸(블러 제거), 하단 내비 선택 표시선.
- 경로형 라벨은 `SectionHeader`, `PageIntroCard`에서 표시하지 않음(`domainPath` prop은 호환용으로 유지).
- 아이콘 `aria-hidden` 명시, 알림 메타 가운데 점 분리.

### 3단계 도메인별 화면 (병렬)

- GPT Sol 6.2 작업자 5명에게 공통 지시서 + 작업자별 지시서(plan4.md)를 주고 동시에 진행. 수정 금지 영역을 정해 파일 충돌 없음.
- 컴포넌트 48개 수정. 범위 밖 파일 수정 없음.
- 점검: FAIL 36 / REFLEX 34 / WARN 8 → FAIL 1 / REFLEX 7 / WARN 2.

### 4단계 통합 검증과 마무리 리뷰

- 유지 항목 대조: 모두 유지. 빌드 성공. 다크·라이트 대비, 좁은 화면, 모달·차트·팝오버·캐러셀 확인.
- 마무리 리뷰를 작업에 참여하지 않은 Claude(Opus 5.5)와 GPT Sol 6.2에게 각각 맡김. 둘 다 판정 fix.
- 지적 13개 중 10개를 GPT Sol 6.2 작업자가 수정하고, Claude가 다시 찍어 채점: 해결 10, 부분 해결 1, 주인에게 넘김 2.
